KisanFlow v9 - Admin Login Fix

Main fix:
- /admin now ALWAYS opens the Admin Login page unless an admin is already logged in.
- A farmer session no longer redirects /admin to the home page.
- /admin/login accepts only the admin username and password and clears any existing farmer session.
- After admin login, /admin opens the slot-management page.
- /dashboard redirects to /admin when an admin session is missing.
- Slot page now previews the slots created for the selected centre/date.
